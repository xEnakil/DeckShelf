## [1.0.0] - 2026-08-16

### Added

- Portable Steam Deck scanner with EmuDeck and RetroDECK directory detection.
- Searchable single-file HTML shelf with filters, duplicate grouping, list checks, exports and storage charts.
- Native Windows WebView2 application with its own window, icon and taskbar entry.
- File-based portable settings and browser fallback.
- Reproducible source build, regression tests and automated release packaging.
