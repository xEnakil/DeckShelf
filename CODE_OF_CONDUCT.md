# Code of conduct

ROM Shelf should be a welcoming project for users and contributors of every background and experience level.

## Expected behavior

- Be respectful, patient and constructive.
- Critique ideas and code without attacking people.
- Assume good intent while accepting correction.
- Respect privacy and never request or publish another person's game library, credentials or personal paths.
- Follow applicable copyright law; do not use this project to distribute copyrighted ROMs or BIOS files.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, deliberate disruption, doxxing and publishing private information are not tolerated in project spaces.

## Enforcement

Report conduct concerns privately to the repository owner through GitHub. Maintainers may edit or remove contributions, comments and other participation that violate this code, and may temporarily or permanently restrict participation. Reports will be handled as confidentially as practical.

This code applies in the repository and in public spaces where someone is representing ROM Shelf.
